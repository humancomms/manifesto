# Sign the Human Comms Manifesto

Signatures are public GitHub pull requests. No account system or private database is used.

## Individual

1. Fork this repository.
2. Copy `signatories/templates/individual.json` to `signatories/individuals/<your-github-username>.json`.
3. Replace the values with your own. `url` is optional and may be removed.
4. Open a pull request against `main`.

By submitting the pull request, you are stating that you have read and adopted the Human Comms Manifesto and that the submitted identity is yours.

## Organization

1. Fork this repository.
2. Copy `signatories/templates/organization.json` to `signatories/organizations/<organization-name>.json` using lowercase kebab-case.
3. Replace the values. `github` is optional and may be removed.
4. Open a pull request against `main`.

The person opening an organization signature must be authorized to make the adoption statement on behalf of that organization. Moderators may ask for evidence of that authority before merging.

## Moderation

Signatures are reviewed before merge. Duplicate, misleading, impersonating, promotional, or unverifiable submissions may be declined. A signer can later request removal through another pull request.
